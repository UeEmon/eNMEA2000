AIS SDR送信エミュレータ

NMEA → GMSK変調 → I/Q → SDR受信部

変調操作

既存エミュレータの出力先：このPCのIP、TCP／UDP 10113
SDR受信部の入力：RTL-TCP、このPCのIP、1235、288000 Hz
同じDockerホストからの接続には host.docker.internal を指定します。

ソフトウェア間での変調・復調試験です。アンテナからの電波出力はありません。

信号条件

保存すると変調を停止します。通常試験は振幅0.65、雑音0、周波数ずれ0、正常FCSを使用します。

試験データ

既存エミュレータのGIS・メッセージ編集画面からTCP／UDP送信できます。ここでは内蔵ケースや貼り付けデータも利用できます。

CU8 / 288000 Hz / 中心162 MHz。分割文は全断片を入力してください。AIVDOもAISペイロードとして変調し、受信側では他船AIVDMとして扱います。

全シナリオには予約タイプや短い試験データがあり、受信エンジンの検証で棄却されるケースも含まれます。
