# 独立Docker TCPエミュレータ

macOSではリポジトリのルートで `bash verify-macos.sh` を実行すると、本体とエミュレータの起動、TCP連接と保存の自動確認まで一括で行えます。

本体システムを起動した後、プロジェクトのルートで `docker compose -f emulator/compose.yaml up -d --build --wait` を実行します。エミュレータ画面は `http://localhost:8090` です。

エミュレータの地図は本体と同じCesiumJSと、同梱のNatural Earth背景図を使います。地図の「開始位置を置く」を選んでクリックすると送信位置を設定できます。「航路点を追加」でクリックした順に最大30点の航路を作ります。マーカーのドラッグで開始位置／航路点を修正し、「針路を指示」で現在位置からクリック地点への針路を設定できます（航路は解除されます）。送信中の地図編集も次の送信から反映します。

Web画面で対地速度（ノット）、針路（度）、AIS船舶数（1～20）、送信間隔（0.2～60秒）、航路周回を指定できます。メッセージタイプのタブ（RMC、GGA、AIS Type 1、AIS Type 5）では、タイプごとに送信の有効・無効を切り替えられます。選択後は「送信開始・設定反映」を押して反映します。タブは左右矢印キー、Home、Endでも切り替えられます。AIS Type 5は開始時と60回ごと、他の有効なタイプは毎回送信します。生成した文はTCP 10111へCRLF区切りで送信します。停止するとTCP接続を閉じます。接続先は環境変数 `NMEA_TARGET_HOST` と `NMEA_TARGET_PORT` で指定します。

別のComposeプロジェクトとして起動し、独立したDockerネットワークから `host.docker.internal:10111` に接続します。`extra_hosts: host-gateway` はLinuxのGitHub Actionsでも同じ経路を使うための指定です。Web UIは既定でローカルホストのみに公開します。接続先のアドレスをWeb画面から変更する機能は設けていません。

端末のPython 3.12から `python scripts/smoke_emulator.py` で2つのCompose間のTCP送信・GIS航路追従・AIS位置情報保存を検証できます。GitHub ActionsではさらにブラウザからCesium地図をクリックして航路・位置がサーバへ反映されることを検証します。用途はシステム試験です。実際のAIS送信器ではありません。

航路末尾に到達すると送信位置を保持して速力0ノットを出します。「航路を周回」を選ぶと先頭の航路点へ戻ります。出力するAIS船舶は基準位置から固定の間隔を空けて同じ航路に沿って移動します。疑似データであり衝突回避や航海判断には使えません。
